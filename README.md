# A.W Above & Beyond Cleaning
1. Firebase config is already inside `index.html`.
2. Firebase console: enable Authentication > Email/Password and create your staff user; Firestore > Rules: paste `firestore.rules` (put your email in it); add your GitHub Pages domain under Authentication > Settings > Authorized domains.
3. Upload photos to `images/` in this repo, then type just the file name (e.g. `hero.jpg`) in the editor. Favicon works the same way.
4. Push to GitHub > Settings > Pages > deploy from `main` / root. Open the site, click **Staff login**, then **✎ Edit** > Save.
